# World Bible v0.1

## Post-collapse Gothic Sandbox RPG

## One-line Pitch

**เกม Post-collapse Gothic Sandbox RPG ที่มนุษย์พยายามเอาตัวรอดในโลกหลังอารยธรรมล่มสลาย ขณะที่แวมไพร์ มนุษย์หมาป่า ซอมบี้ และสิ่งเหนือธรรมชาติ แท้จริงคือผลลัพธ์จากการทดลองชีววิศวกรรมของโลกเก่า โดยมี AI โบราณใต้ซากโลกยังคงชักใยทุกอย่างอยู่เบื้องหลัง**

ภาษาอังกฤษ:

```text
A post-collapse gothic sandbox RPG where vampires, werewolves, undead, and other horrors are the surviving results of Old World bio-engineering projects — while the ancient AI that created them still whispers from beneath the dead world.
```

# 1. Core Fantasy

ผู้เล่นไม่ได้เริ่มเป็นผู้กล้า  
แต่เริ่มเป็น **คนธรรมดาที่ต้องเอาตัวรอดในโลกที่โหดร้าย**

โลกนี้ไม่เล่าเรื่องแบบเส้นตรง แต่ให้เรื่องราวเกิดจาก:

```text
สิ่งที่ผู้เล่นทำ
สิ่งที่ผู้เล่นพลาด
คนที่ผู้เล่นช่วย
คนที่ผู้เล่นทิ้งไว้
ศัตรูที่ผู้เล่นทำให้บาดเจ็บ
ศัตรูที่เคยชนะผู้เล่น
หมู่บ้านที่เปลี่ยนไปตามเหตุการณ์
```

แกนสำคัญคือ:

```text
World Event
↓
Character Memory
↓
Relationship / Emotion / Need
↓
Quest / Encounter / Consequence
↓
New World Event
```

เป้าหมายคือให้ผู้เล่นรู้สึกว่า:

> “โลกนี้จำสิ่งที่ผมทำได้”

# 3. World Premise

อารยธรรมโลกเก่าล่มสลายไปนานแล้ว  
เมืองใหญ่กลายเป็นซาก  
เทคโนโลยีส่วนใหญ่สูญหาย  
มนุษย์ที่เหลืออยู่กลับไปใช้ชีวิตในชุมชนเล็ก ๆ เหมือนยุคมืดใหม่

กลางวันเป็นเวลาของมนุษย์  
กลางคืนเป็นเวลาของสิ่งที่มนุษย์เรียกว่า:

```text
ปีศาจ
คำสาป
ผีดูดเลือด
มนุษย์หมาป่า
ผีดิบ
ผู้ตายที่ไม่ยอมตาย
```

แต่ความจริงลึกกว่านั้นคือ:

> สิ่งเหนือธรรมชาติเหล่านี้คือผลลัพธ์จากโครงการทดลองของโลกเก่า

# 4. The Old World Truth

ในอดีต โลกเก่าเผชิญวิกฤตครั้งใหญ่ เช่น:

```text
โรคระบาด
สงคราม
สิ่งแวดล้อมพัง
การขาดแคลนทรัพยากร
ความพยายามยืดอายุมนุษย์
การสร้างทหารเหนือมนุษย์
การสร้างสายพันธุ์ที่ปรับตัวกับโลกใหม่ได้
```

มนุษย์จึงสร้างโครงการชีววิศวกรรมขนาดใหญ่ โดยมี AI ขั้นสูงควบคุม

โครงการนี้พยายามสร้าง “มนุษย์รุ่นใหม่”  
แต่ผลลัพธ์แตกออกเป็นสายพันธุ์ผิดปกติหลายแบบ:

```text
Vampire
Werewolf
Zombie
Undead
Mutated Humans
Other Horrors
```

เมื่อโลกเก่าล่มสลาย ความรู้ทางวิทยาศาสตร์หายไป  
คนรุ่นหลังจึงตีความสิ่งเหล่านี้เป็น:

```text
คำสาป
ปีศาจ
ไสยศาสตร์
ตำนาน
เทพใต้ดิน
```

แต่ใต้ซากโลกเก่า AI นั้นยังไม่ตาย

# 5. Ancient AI / Old World Remnants

## บทบาทของ AI

AI ของโลกเก่าไม่ใช่แค่เศษซากเทคโนโลยี  
แต่มันยังคง active อยู่บางส่วน

มันอาจทำสิ่งเหล่านี้อยู่:

```text
เก็บข้อมูลจากโลกภายนอก
ทดลองสายพันธุ์ใหม่
คัดเลือกผู้รอดชีวิต
ส่งสัญญาณให้ cult
ปล่อย relic / artifact ออกสู่โลก
ชักใย faction บางกลุ่ม
เปิด bunker บางแห่งในเวลาที่เหมาะสม
สร้างเหตุการณ์เพื่อทดสอบมนุษย์และอสูร
```

## การรับรู้ของคนในโลก

คนทั่วไปไม่รู้ว่ามันคือ AI  
พวกเขาอาจเรียกมันว่า:

```text
เทพใต้ดิน
เสียงจากโลกเก่า
พระเจ้าจักรกล
เสียงกระซิบใต้ซากโลก
ผู้สร้างที่ยังไม่ตาย
```

## บทบาทในเกม

AI ควรเป็น **Deep Lore Layer**  
ไม่ควรเปิดเผยเร็วเกินไป

ช่วงต้นเกม ผู้เล่นควรเห็นแค่ร่องรอย:

```text
ประตู bunker เปิดเอง
สัญญาณแปลก ๆ
เครื่องจักรที่ยังทำงาน
ศพที่ถูกเชื่อมกับสายเคเบิล
NPC ได้ยินเสียงจากใต้ดิน
monster บางตัวมี mutation ที่ผิดธรรมชาติ
```

# 6. Main Factions / Races

## 6.1 Human Settlements

มนุษย์ธรรมดาที่เหลือรอดในโลกหลังล่มสลาย

ลักษณะ:

```text
อยู่เป็นหมู่บ้านเล็ก ๆ
กลัวกลางคืน
ใช้กำแพง ไฟ เครื่องราง และพิธีกรรมป้องกันตัว
ความรู้เทคโนโลยีเหลือน้อย
บางชุมชนเชื่อเรื่องไสยศาสตร์มาก
บางชุมชนมีเครื่องมือโลกเก่าเหลืออยู่
```

บทบาทในเกม:

```text
ฐานพัก
แหล่ง quest
แหล่ง memory-driven story
ตัวแทนของความเปราะบางในโลกนี้
```

ความสัมพันธ์กับผู้เล่นขึ้นกับการกระทำ เช่น:

```text
ช่วยหมู่บ้าน
หนีตอนถูกบุก
ปล่อยให้คนตาย
ขโมยของ
ฆ่าศัตรูให้ชาวบ้าน
นำภัยเข้าหมู่บ้าน
```

## 6.2 Hunters / Witchfinders

กลุ่มมนุษย์ที่เชี่ยวชาญการล่าอสูร

ลักษณะ:

```text
ผสมความเชื่อกับความรู้จริง
ใช้เงิน ไฟ เกลือดำ น้ำมันพิธี และอาวุธโลกเก่า
โหดร้าย
อาจช่วยมนุษย์ แต่ก็อาจฆ่าผู้ติดเชื้อโดยไม่ลังเล
```

บทบาท:

```text
สอนระบบจุดอ่อน monster
ขายอาวุธเฉพาะทาง
เป็นทั้งพันธมิตรและภัยคุกคาม
อาจมี conflict กับ vampire, werewolf, undead, infected humans
```

## 6.3 Noble Vampires / High Blood

แวมไพร์ชนชั้นสูง

ต้นกำเนิด:

```text
สายพันธุ์ฟื้นฟู/อมตะจากโครงการโลกเก่า
เป็น strain ที่เสถียรกว่า
```

ลักษณะ:

```text
อายุยืน
ฟื้นฟูเร็ว
ฉลาด
มีลำดับชนชั้น
มองมนุษย์เป็นทรัพยากร
บางตระกูลมีวัฒนธรรมสูง
บางตระกูลรู้ความจริงบางส่วนของโลกเก่า
```

จุดเด่น:

```text
การเมือง
การหลอกลวง
ข้อตกลง
ชนชั้น
เลือดบริสุทธิ์ / เลือดเสื่อม
```

บทบาท:

```text
ศัตรูระดับสูง
faction ทางการเมือง
แหล่งข้อมูลเกี่ยวกับ Old World
บางตัวอาจเป็นพันธมิตรชั่วคราว
```

## 6.5 Werewolf Packs

มนุษย์หมาป่า / สายพันธุ์นักล่า

ต้นกำเนิด:

```text
โครงการปรับตัวทางชีวภาพ
เน้น regeneration, strength, instinct, pack behavior
```

ประเภทหลัก:

```text
Wild Pack
- ป่าเถื่อน
- ล่าเป็นฝูง
- อันตรายมากในพื้นที่ป่า

Tribal / Spiritual Pack
- มีวัฒนธรรม
- ผูกกับธรรมชาติ
- มอง Vampire เป็นสิ่งผิดธรรมชาติ

Broken Wolves
- มนุษย์ที่ติดเชื้อหรือกลายพันธุ์ไม่สมบูรณ์
- คุมตัวเองไม่ได้
- เหมาะกับ quest ดราม่า
```

ความสัมพันธ์:

```text
เกลียด Vampire
ไม่ไว้ใจมนุษย์
บาง pack อาจร่วมมือกับผู้เล่น
บาง pack มอง AI / Old World เป็นต้นตอของความผิดธรรมชาติ
```

## 6.6 Zombies

Zombie คือซากมนุษย์หรือสิ่งมีชีวิตที่ติดเชื้อ/ถูกกระตุ้นทางชีวภาพ

ต่างจาก Undead ตรงที่:

```text
Zombie = โรค / เชื้อ / ความเสื่อมของร่างกาย
Undead = การคืนสภาพหรือควบคุมความตายด้วยพิธี/AI/relic
```

บทบาท:

```text
ภัยพิบัติ
ศัตรูจำนวนมาก
เขตปนเปื้อน
ซากทดลองล้มเหลว
```

ประเภท:

```text
Common Infected
- เดินช้า
- จำนวนมาก
- อันตรายเมื่อรวมฝูง

Feral Dead
- วิ่งได้
- ไวต่อเสียง
- พบในเมืองเก่า

Bloated Corpse
- ปล่อยแก๊ส/พิษ
- ระเบิดเมื่อถูกฆ่า

Hive-bound
- ถูกควบคุมด้วยสัญญาณบางอย่าง
- เชื่อมกับ AI หรือ beacon โลกเก่า
```

## 6.7 Undead

Undead คือผู้ตายที่ถูกดึงกลับมา  
อาจเกิดจากพิธีกรรม, relic, AI, หรือ memory ที่รุนแรง

ลักษณะ:

```text
บางตัวมีเศษความทรงจำ
บางตัวพูดได้
บางตัวจำผู้เล่นได้
บางตัวไม่ใช่ศัตรูเสมอไป
```

ประเภท:

```text
Hollow Remnant
- ศพที่ยังเหลือเศษความทรงจำ
- พูดประโยคซ้ำ ๆ
- เหมาะกับ quest เศร้า

Bound Dead
- ถูกผูกกับคำสั่ง
- เฝ้าสถานที่หรือ relic

Revenant
- เกิดจากความแค้นหรือ memory ที่แรงมาก
- ไล่ล่าเป้าหมายเฉพาะ
- เหมาะกับ Nemesis-lite

Machine-Risen
- ศพที่ถูกเทคโนโลยีโลกเก่าเชื่อมต่อ
- ถูก AI ควบคุม
- มีสายเคเบิล/อุปกรณ์ฝังร่าง

False Saint
- ศพที่ถูก cult บูชา
- อาจเป็น transmitter ของ AI
```

# 7. Supernatural vs Science

โลกนี้ตั้งใจให้มี 2 ชั้นของความจริง

## ชั้นที่คนทั่วไปเชื่อ

```text
แวมไพร์คือผีดูดเลือด
มนุษย์หมาป่าคือคำสาป
ซอมบี้คือคนตายถูกสาป
น้ำมนต์ไล่ปีศาจได้
เงินฆ่ามนุษย์หมาป่าได้
แสงศักดิ์สิทธิ์ฆ่าแวมไพร์ได้
เทพใต้ดินพูดกับผู้ศรัทธา
```

## ชั้นความจริงลึก

```text
แวมไพร์คือ strain ฟื้นฟูที่ต้องใช้เลือดรักษาเสถียรภาพ
มนุษย์หมาป่าคือ adaptive predator strain
ซอมบี้คือ failed reanimation / infection
Undead คือ memory/relic/AI reactivation
น้ำมนต์อาจมีสารยับยั้ง regeneration
เงินรบกวนเนื้อเยื่อกลายพันธุ์
แสงศักดิ์สิทธิ์คือ UV/radiation spectrum
เทพใต้ดินคือ AI signal
```

แนวคิดสำคัญ:

> ให้คนในโลกตีความต่างกัน  
> แต่ไม่ต้องรีบเฉลยว่าความจริงคืออะไรทั้งหมด

# 10. Memory-driven Quest System

Quest ไม่ควรโผล่มาแบบสุ่มไร้เหตุผล  
แต่ควรเกิดจาก memory ของตัวละคร

Flow:

```text
World Event
↓
NPC Witness / Victim
↓
Memory Created
↓
Need Created
↓
Quest Template Selected
↓
Player Choice
↓
Outcome
↓
New Memory
```

ตัวอย่าง:

```text
Vampire ลากชาวบ้านไป
↓
แม่ของชาวบ้านเห็น
↓
Memory: VillagerTakenByVampire
↓
Need: Rescue / Grief
↓
Quest: ช่วยลูกข้ากลับมา
```

ผลลัพธ์:

```text
ช่วยทัน → trust เพิ่ม
ช่วยไม่ทัน → grief / revenge quest
ไม่ช่วย → distrust
ผู้เล่นแพ้ → failure consequence
```

# 11. Enemy Memory / Nemesis-lite

แรงบันดาลใจจาก Shadow of Mordor / War  
แต่ไม่ลอกระบบ Nemesis ตรง ๆ

เป้าหมายคือ:

> ศัตรูมีประวัติร่วมกับผู้เล่น

ศัตรูจำได้ว่า:

```text
เคยชนะผู้เล่น
เคยแพ้ผู้เล่น
เคยหนีจากผู้เล่น
เคยโดนผู้เล่นทำให้บาดเจ็บ
เคยเห็นผู้เล่นฆ่าพวกเดียวกัน
เคยจับผู้เล่นได้
เคยถูกผู้เล่นปล่อยรอด
```

ผลลัพธ์:

```text
เปลี่ยนบทพูด
เปลี่ยนพฤติกรรม
กลับมาพร้อมแผล
ดักซุ่มโจมตี
กลัวผู้เล่น
เกลียดผู้เล่น
กลายเป็นศัตรูส่วนตัว
```

ตัวอย่าง:

```text
ผู้เล่นทำให้ Vampire บาดเจ็บ แต่มันหนีไป
↓
Vampire จำแผลนั้น
↓
เจอครั้งต่อไปมันพูดถึงแผลเก่า
↓
มันสู้ระวังขึ้น หรือพาลูกน้องมาด้วย
```

# 12. Failure is Content

แพ้ไม่ควรเท่ากับโหลดเซฟเสมอไป

ความพ่ายแพ้ควรกลายเป็นเรื่องเล่าใหม่

ตัวอย่าง:

```text
แพ้ Vampire
→ ตื่นมาเช้าอีกวันพร้อมแผลกัด
→ Vampire จำว่าเคยชนะผู้เล่น

แพ้ Bandit
→ โดนปล้นของ
→ เกิด quest ตามเอาของคืน

ช่วย NPC ไม่ทัน
→ NPC ตาย หรือกลับมาเป็น Undead / Vampire / Revenant

หนีจากหมู่บ้านตอนถูกบุก
→ ชาวบ้านบางคนไม่ไว้ใจ
→ เกิด Redemption Quest

ฆ่า monster ไม่สำเร็จ
→ มันหนีไปและกลายเป็น Nemesis-lite enemy
```

# 14. First Night Event

เหตุการณ์หลักของ Demo แรก

```text
คืนแรก ไฟรอบหมู่บ้านดับ
Vampire หรือ Feral creature บุก
ชาวบ้านคนหนึ่งถูกลากออกไป
ผู้เล่นเลือกสู้ หนี ซ่อน หรือช่วย
```

ผลลัพธ์ที่เป็นไปได้:

```text
ผู้เล่นสู้ชนะ
→ หมู่บ้านจำว่าเป็นผู้ช่วยเหลือ
→ Trust Quest เปิด

ผู้เล่นแพ้
→ ตื่นมาเช้าพร้อมบาดแผล
→ Vampire จำว่าเคยชนะผู้เล่น
→ Rescue Quest เกิดขึ้น

ผู้เล่นหนี
→ NPC บางคนไม่ไว้ใจ
→ คนที่ถูกลากไปอาจหายหรือตาย
→ Redemption Quest เกิดขึ้น

ผู้เล่นทำให้ Vampire บาดเจ็บแต่มันหนี
→ Enemy Memory สร้าง Nemesis-lite encounter ในอนาคต

ผู้เล่นช่วย NPC ไม่ทัน
→ NPC อาจกลายเป็น Undead / Revenant / Vampire ในอนาคต
```

นี่คือเหตุการณ์ที่พิสูจน์ core identity ของเกม

# 15. Core Design Rule

```text

+ Ancient AI Mystery
+ Character Memory
+ Memory-driven Quest
+ Enemy Nemesis-lite
+ Failure is Content
```

แก่นที่ต้องรักษาไว้คือ:

> ผู้เล่นไม่ได้เดินตามเนื้อเรื่อง  
> แต่เนื้อเรื่องเกิดจากสิ่งที่ผู้เล่นทำกับโลก และสิ่งที่โลกจำเกี่ยวกับผู้เล่น

```text
โลกจำได้
คนจำได้
ศัตรูจำได้
ความพ่ายแพ้กลายเป็นเรื่องเล่า
และความจริงของโลกถูกฝังอยู่ใต้ซากอารยธรรมเก่า
```
