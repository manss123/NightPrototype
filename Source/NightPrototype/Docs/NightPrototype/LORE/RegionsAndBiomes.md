# Regions And Biomes

## Document Role

This document expands the canonical region set from [[LoreCanon]].

Regions are not only visual themes. Each region defines pressure, dominant fear, faction influence, and event hooks.

## Purpose

Regions should define pressure, not only scenery.

Every settlement should have:

```text
local fear
local dependency
dominant threat
political pressure
possible event hooks
```

Core rule:

```text
Villages should not be only names on a map.
Each one should be shaped by what it fears and what it must rely on.
```

## Region Power Map

```text
Ashwake / Dust Borderlands
-> humans can still survive, but are fragile

Blackroot / Rotwood
-> forest and werewolf territory dominate

Gravespine Heights
-> hunters control routes, but old stone/old world forces remain

Noctis Ruins
-> vampires control the city and humans become resources

Bloodmarsh
-> death, witches, and undead dominate

Pale Expanse
-> Machine Church and Old World signals become visible

Pale Underworld
-> truth layer below the world
```

## Ashwake / Dust Borderlands

Visual and gameplay identity:

```text
dry land
low walls
water scarcity
small farms
night fear
simple defenses
```

Common fears:

```text
vampires at night
bandits
water loss
fire going out
```

Good for:

```text
first village
memory drama
first raid
corpse investigation
missing villager
```

Emberwall currently fits this role.

## Canal / Transition Villages

Identity:

```text
old water infrastructure
canals
bridges
wet ruins
witch or dhampir presence
old world contamination
```

Fears:

```text
bad water
hidden infection
things under bridges
old machines below the canal
```

Good for:

```text
witch introduction
water politics
hidden dhampir
old world clue
```

## Blackroot / Rotwood

This is the forest/werewolf region.

Forest hidden hamlets are the most common human settlement type here.

Identity:

```text
hidden in forest
low light
small paths
ritual boundaries
outsider distrust
```

Fears:

```text
breaking pack law
entering forbidden woods
angered forest spirits or old kin
hunters discovering the hamlet
```

Good for:

```text
werewolf territory rules
witch bargain
pack negotiation
outsider suspicion
```

## Gravespine Heights

This is the hunter-controlled mountain route region.

Mountain watch settlements are the most common human settlement type here.

Identity:

```text
strict gates
watchtowers
hunter presence
checkpoints
burn pits
stone shrines
```

Fears:

```text
infection
impurity
smugglers
monsters crossing mountain passes
```

Good for:

```text
hunter politics
lawful brutality
checkpoint choices
suspected infection
```

## Noctis Ruins

This is the vampire-dominated old city region.

Vampire-shadow villages and blood-tax districts belong here.

Identity:

```text
quiet streets
people avoiding questions
missing villagers
blood tax
ghoul influence
secret obedience
```

Fears:

```text
speaking names aloud
breaking vampire bargain
night summons
thrall leaders
```

Good for:

```text
infiltration
social horror
blood debt
secret questline
```

## Bloodmarsh

This is the witch, plague, and undead marsh region.

Marsh stilt villages are the most common human settlement type here.

Identity:

```text
raised houses
small boats
fog
grave bells
witch influence
strict death rituals
```

Fears:

```text
unburned bodies
water
fog
dead returning
funeral bells
```

Good for:

```text
undead stories
witch medicine
body recovery
revenant quests
```

## Pale Expanse

This is the surface region where Machine Church and Old World signals become visible.

Pale cult settlements belong here.

Identity:

```text
dry white ground
quiet residents
machine symbols
dig sites
signal shrines
children drawing machines
```

Fears:

```text
the signal stopping
voices underground
failed ascension
machine judgment
```

Good for:

```text
Machine Church introduction
AI cult
old world facility access
late-game truth clues
```

## Pale Underworld

This is not a normal biome.

It is a truth layer:

```text
AI facility
containment zone
old lab
reanimation chamber
machine chapel
sealed colony
failed experiment ward
```

Good for:

```text
AI memory manipulation
old world origin reveals
machine-risen enemies
late-game consequence checks
```

## Human World Shape

The known region should eventually have:

```text
1 major human city
3 secondary towns / forts
6-10 important villages
multiple outposts and camps
```

Potential examples:

```text
Cindergate
Grimhold
Brightwatch
Emberwall
Canal village
Forest hidden hamlet
Marsh stilt village
Blood-tax village
Witch grove
Hunter watch camp
```

This creates a world where humans exist in numbers, but safety is uneven.

## Settlement Design Checklist

For every settlement, define:

```text
What does it fear?
What does it depend on?
Who protects it?
Who secretly controls it?
What happens at night?
What event would destabilize it?
What memory would change its dialogue?
```
