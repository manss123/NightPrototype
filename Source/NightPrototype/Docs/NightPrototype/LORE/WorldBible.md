## One-Line Pitch

NightPrototype is a post-collapse gothic sandbox RPG where humans survive in a broken world of vampires, werewolves, undead, and other horrors that are secretly the surviving results of Old World bio-engineering, while an ancient AI still whispers beneath the dead world.

## Core Fantasy

The player does not begin as a chosen hero.

The player begins as a vulnerable person trying to survive in a harsh world.

The story is not primarily linear. It should emerge from:

```text
what the player does
what the player fails to do
who the player saves
who the player abandons
which enemies survive
which enemies remember the player
which villages change because of events
```

Core loop:

```text
World Event
-> Character Memory
-> Relationship / Emotion / Need
-> Dialogue / Quest / Encounter / Consequence
-> New World Event
```

Player-facing goal:

```text
The world remembers what happened.
```

## World Premise

Old civilization collapsed long ago.

Cities became ruins. Most technology was lost. Humans fell back into small communities that live like a new dark age.

Day belongs to humans.

Night belongs to things humans call:

```text
demons
curses
vampires
werewolves
walking dead
the dead who refuse to die
```

The deeper truth:

```text
Many supernatural horrors are the surviving results of Old World experiments.
```

## Old World Truth

The Old World faced cascading crises:

```text
plague
war
environmental collapse
resource scarcity
life extension
super-soldier development
adaptive human strain experiments
```

Advanced AI-managed bio-engineering attempted to create new kinds of humans.

The result fractured into unstable lineages:

```text
Vampires
Werewolves
Zombies
Undead
Mutated Humans
Other Horrors
```

After the collapse, scientific understanding became myth.

People now interpret old science as:

```text
curses
demons
witchcraft
legends
gods below the earth
```

The ancient AI did not fully die.

## Ancient AI

The AI is a deep lore layer, not an early-game exposition device.

Possible current actions:

```text
collecting surface data
testing strains
selecting survivors
sending signals to cults
releasing relics or artifacts
manipulating factions
opening bunkers at chosen times
creating events to test humans and monsters
```

How people interpret it:

```text
god beneath the earth
voice of the Old World
machine god
whisper below the ruins
undead creator
```

Early-game hints only:

```text
bunker doors opening by themselves
strange signals
machines that still work
bodies wired into cables
NPCs hearing voices underground
monsters with unnatural mutations
```

## Supernatural vs Science

The world has two layers of truth.

## Common Belief

```text
vampires are blood-drinking spirits
werewolves are curses
zombies are cursed dead
holy water repels evil
silver kills werewolves
holy light kills vampires
the underground god speaks to believers
```

## Deeper Truth

```text
vampires are regenerative strains stabilized by blood
werewolves are adaptive predator strains
zombies are failed reanimation / infection cases
undead are memory, relic, or AI-driven reactivation
holy water may contain regeneration inhibitors
silver disrupts mutated tissue
holy light may be UV or controlled radiation
the underground god may be an AI signal
```

Design rule:

```text
Let people in the world interpret the truth differently.
Do not reveal the full truth too early.
```

They are useful, dangerous, and morally harsh.

They use:

Gameplay role:

```text

```

It applies to:


## Failure Is Content

Failure should create new story instead of always forcing reload.

Examples:

```text
Player loses to vampire
-> wakes the next morning with wounds
-> vampire remembers victory

Player loses to bandits
-> items are stolen
-> recovery quest appears

Player fails to save NPC
-> NPC dies, changes faction, or returns as undead/vampire/revenant

Player flees village attack
-> villagers distrust player
-> redemption quest appears

Enemy escapes wounded
-> enemy becomes nemesis-lite candidate
```

## Demo Identity

The demo should happen in or near Emberwall, inside the Ashwake / Dust Borderlands region.

The first playable demo should prove the core identity:

```text
small village
few NPCs
night threat
memory event
enemy memory
failure consequence
dialogue changes
world reacts
```

## First Major Scenario

The first night is not a permanent hard-coded system dependency.

It is a demo scenario that proves the reusable encounter model.

Scenario shape:

```text
Night falls
-> village protection fails
-> feral threat attacks
-> one villager may be taken
-> player fights, flees, hides, helps, or loses
-> world records outcome
-> NPCs and enemies remember
```

Possible outcomes:

```text
player wins
-> village trust increases

player loses
-> player survives with consequence
-> enemy remembers victory

player flees
-> distrust / redemption

enemy escapes wounded
-> nemesis-lite seed

victim is not saved
-> rescue, grief, revenge, or transformation hook
```

## Demo MVP Scope

Keep the first demo small:

```text
1 small village
2-3 important NPCs
1 feral threat
1 optional undead/zombie clue or minor encounter
1 reusable encounter template
basic character memory
basic enemy memory
basic consequence system
2-3 quest templates later
dialogue changes from memory
defeat does not always mean game over
```

## Not Now

Avoid expanding into these too early:

```text

full faction war
economy simulation
base building
detailed NPC schedules
multi-character party control
large skill tree
procedural world
modern city systems
vehicles / police / CCTV
```

## Core Design Test

Every new system should answer:

```text
Does this help create player story?
```

If yes, consider it.

If no, defer it.
