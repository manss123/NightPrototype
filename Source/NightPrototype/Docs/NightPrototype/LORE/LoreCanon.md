# Lore Canon

## Purpose

This file is the source of truth for lore terminology and setting consistency.

Other lore files may go deeper, but they should not contradict this document.

Use this file when deciding:

```text
What is the real name of a faction?
What does a region mean?
What is public myth versus hidden truth?
What should stay mysterious?
What belongs in the first demo?
```

## Core Identity

NightPrototype is:

```text
Post-collapse Gothic Sandbox RPG
+ Kenshi-like weak-to-legend progression
+ Event/story-driven world
+ Bio-engineered monsters interpreted as supernatural horror
+ Ancient AI mystery beneath the world
+ Character memory and enemy memory
+ Failure becomes story
```

The game should not become:

```text
scripted hero RPG
generic medieval fantasy
modern urban vampire game
pure sci-fi shooter
large faction simulator before the core demo works
```

## Truth Layers

The setting has three layers of truth.

## Layer 1: Folk Belief

What most villagers believe:

```text
Vampires are cursed blood-drinking dead.
Werewolves are forest curses.
Zombies are cursed corpses.
Undead are spirits that failed to pass on.
Holy water, silver, fire, salt, and ritual marks repel evil.
The underground voice is a god, devil, saint, or curse.
```

This is the language used by most NPCs.

## Layer 2: Practical Occult

What hunters, witches, and experienced survivors understand:

```text
Some rituals work, but not always for the reason people think.
Silver harms certain transformed tissue.
Fire disrupts regeneration.
Black salt and oils can affect undead bindings.
Old relics can mimic miracles.
Some monsters remember being human.
```

This layer should appear through tools, rumors, and quests.

## Layer 3: Old World Truth

The hidden truth:

```text
Many monsters descend from Old World bio-engineering projects.
Ancient AI systems still operate beneath ruined civilization.
Some "curses" are unstable strains, failed reanimation, signal control, or mutation.
Religion, ritual, and superstition often describe real phenomena through broken language.
```

This layer should remain mostly hidden in the early demo.

## Canonical Faction Set

## Human Settlements

Fragile human communities surviving through walls, fire, ritual, trade, and compromise.

Role:

```text
memory anchors
quest sources
settlement consequence receivers
social pressure
```

## Hunters / Witchfinders

Human monster hunters who protect settlements but often become brutal.

Role:

```text
monster weakness tutorial
moral pressure
anti-infection politics
specialized tools
```

## Witches / Blood Alchemists

Healers, curse doctors, alchemists, and keepers of dangerous knowledge.

Role:

```text
medicine
monster knowledge
forbidden cures
bridge between folk belief and Old World truth
```

## Noble Vampires / High Blood

Stable vampire lineages with politics, hierarchy, blood contracts, and partial knowledge of the Old World.

Role:

```text
political monster faction
late-game manipulation
blood debt
Old World clue holder
```

## Feral Vampires / Low Blood

Unstable vampire strains, often hungry and violent, but not always mindless.

Role:

```text
early night threat
intro raid threat
nemesis-lite candidate
proof that monsters can remember
```

## Werewolf Packs

Adaptive predator lineages organized around territory, pack law, instinct, and sometimes old forest culture.

Role:

```text
territorial threat
pack politics
anti-vampire monster faction
possible negotiated faction later
```

## Broken Wolves

Unstable or incomplete werewolf transformations.

Role:

```text
tragic enemy
infection drama
witch/hunter moral conflict
```

## Zombies / Infected Dead

Biological failure, infection, or failed reanimation.

Role:

```text
outbreak pressure
crowd threat
contaminated zones
failed Old World experiment evidence
```

## Undead / Revenants

Dead beings returned by ritual, relic, AI signal, binding, or extreme memory.

Role:

```text
memory horror
tragic quests
moral ambiguity
death is not always final
```

## Machine Church / AI Cult

People who worship or serve signals from beneath the world.

Canonical usage:

```text
Machine Church = organized faction/religion.
AI Cult / Machine Faith = broader belief phenomenon.
```

Role:

```text
bridge to Old World truth
late-game cult pressure
source of Machine-Risen enemies
```

## Old World Remnants

Ruined technology, bunkers, AI fragments, automated systems, labs, relics, and containment failures.

Role:

```text
truth layer
rare tools
late-game horror
source of many monster origins
```

## Optional / Secondary Groups

These exist as expansion hooks, not first-demo requirements:

```text
Dhampir
Ghouls / Blood Thralls
Old Forest Kin
Stonebound / Gargoyles
Chimeras / Fleshcrafted
Machine-Risen
False Saints
```

They should be introduced only when they support a playable event, quest, or region.

## Canonical Region Set

## Ashwake / Dust Borderlands

Human frontier, dry villages, weak walls, water scarcity, night danger.

Emberwall belongs here.

Primary pressure:

```text
fragile human survival
feral night threat
first memory-driven village drama
```

## Blackroot / Rotwood

Forest and werewolf territory.

Primary pressure:

```text
pack law
territorial rules
hidden hamlets
witch bargains
```

## Gravespine Heights

Mountain routes, hunter forts, checkpoints, old stone shrines.

Primary pressure:

```text
hunter control
infection suspicion
route politics
stone/old world secrets
```

## Noctis Ruins

Old city ruins dominated by vampire power.

Primary pressure:

```text
blood tax
thralls
vampire class politics
human resource extraction
```

## Bloodmarsh

Marshland of witches, plague, undead, death rituals, and revenants.

Primary pressure:

```text
death does not stay dead
witch medicine
strict corpse rituals
memory of the dead
```

## Pale Expanse

Dry, pale, quiet region where Machine Church and Old World signals become visible.

Primary pressure:

```text
machine faith
dig sites
signal cults
truth leaking upward
```

## Pale Underworld

Below-world truth layer: AI facilities, labs, containment zones, reanimation chambers.

Primary pressure:

```text
Old World truth
AI testing
machine horror
world memory
```

## Canonical Demo Focus

The first demo should stay in or near:

```text
Emberwall
Ashwake / Dust Borderlands
```

Required demo ideas:

```text
small village
few important NPCs
one feral threat
first reusable encounter
combat outcome
world event record
NPC dialogue reaction
enemy memory / nemesis-lite seed
defeat creates consequence
```

Do not require:

```text
full faction war
large city
procedural NPC generation
full quest generator
Old World truth reveal
complete economy
large world map
```

## Design Test

Every lore addition should answer at least one question:

```text
What event can this create?
What memory can this create?
What relationship can this change?
What encounter can this drive?
What consequence can the player see?
```

If it only sounds cool but does not create playable consequence, keep it as future background.
